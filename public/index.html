📖 API — hướng dẫn nhanh

1 · Chạy gateway (muse2api, OpenAI-compatible)

cd E:\Tools\PC\muse\muse2api
.venv\Scripts\python.exe -m muse2api        # → http://127.0.0.1:18610

2 · Thêm account muse.ai vào pool

  1. Bấm Khởi động gateway nếu chưa chạy (cần MUSE2API_HEADLESS=false trong muse2api/.env để thấy cửa sổ Chrome).
  2. Bấm Mở muse.ai trong Chrome → đăng nhập muse.ai (mã xác thực SMS/email).
  3. Bấm Thêm account — server tự đọc cookie muse.ai qua CDP và POST /admin/accounts.

Cách thủ công (terminal): .venv\Scripts\python.exe import_account.py, hoặc POST /admin/accounts với 4 cookie hatch_sess, hatch_gw, hatch_vml, hatch_native_auth_device — xem README gốc của muse2api.

3 · API key

Key m2a-… dùng cho cả /v1/* lẫn dashboard. Key hiện tại nằm trong muse2api/.env (MUSE2API_API_KEY). Tạo key mới: dashboard → API keys, hoặc POST /admin/keys — plaintext chỉ hiện 1 lần. Cũng có thể nhập key vào ⚙️ Cài đặt của Studio (hồ sơ "muse2api local").

4 · Gọi API trực tiếp

Base URL: http://127.0.0.1:18610/v1 — mọi SDK/client OpenAI chỉ cần đổi base_url.

# Chat (stream SSE)
curl "http://127.0.0.1:18610/v1/chat/completions" -H "Authorization: Bearer %KEY%" -H "Content-Type: application/json" -d "{\"model\":\"muse-chat\",\"stream\":true,\"messages\":[{\"role\":\"user\",\"content\":\"xin chào\"}]}"

# Tạo ảnh
curl "http://127.0.0.1:18610/v1/images/generations" -H "Authorization: Bearer %KEY%" -H "Content-Type: application/json" -d "{\"model\":\"muse-image\",\"prompt\":\"a small gold coin on velvet\",\"size\":\"1024x1024\"}"

# Tạo video: POST /v1/videos  →  poll GET /v1/videos/{task_id} đến khi completed
curl "http://127.0.0.1:18610/v1/videos" -H "Authorization: Bearer %KEY%" -H "Content-Type: application/json" -d "{\"model\":\"muse-video\",\"prompt\":\"flying through clouds\",\"duration\":6,\"aspect_ratio\":\"16:9\"}"
ModelDùng cho
muse-chatChat (stream/non-stream, multi-turn)
muse-imageTạo ảnh, sửa ảnh tham chiếu
muse-videoTạo video (task + poll)

5 · Lỗi thường gặp

Triệu chứngNguyên nhân & cách xử lý
401 invalid or missing API keySai/thiếu key — lấy lại trong dashboard, hoặc kiểm tra MUSE2API_API_KEY trong muse2api/.env.
Log loaded 0 account(s) / không tạo được gìPool rỗng — làm bước 2 (import account).
Account trạng thái invalidCookie hết hạn — đăng nhập lại muse.ai rồi chạy lại import_account.py.
Account trạng thái coolingHết quota tạm thời — tự quay lại sau cooldown (30s).
Dashboard không vào đượcDán đúng key admin — mặc định trùng MUSE2API_API_KEY.
